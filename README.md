# 📊 Customer Segmentation Analysis

A complete **Customer Segmentation Analysis** project built using **Power BI**, **Excel**, and **RFM (Recency, Frequency, Monetary) Analysis** to identify valuable customer groups and generate business-driven insights for marketing and sales optimization.

---

## 🚀 Project Overview

This project focuses on analyzing customer purchasing behavior using transactional sales data.  
The objective is to divide customers into meaningful segments such as:

- 🏆 Champions
- 💎 Loyal Customers
- 🌱 Potential Loyalists
- ⚠️ At-Risk Customers
- ❌ Lost Customers

By applying segmentation techniques, businesses can:

- Improve customer retention
- Increase customer lifetime value (CLV)
- Create personalized marketing campaigns
- Optimize sales strategies
- Improve ROI on marketing spend

---

## 📌 Objectives

- Analyze customer purchase behavior
- Perform RFM-based customer segmentation
- Identify high-value and low-engagement customers
- Create an interactive Power BI dashboard
- Generate actionable business recommendations
